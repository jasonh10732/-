# 暑假大冒險 ☀️ Summer Quest

把你的暑假目標，變成一個**每天打卡、會升等、有 AI 夥伴打氣**的小遊戲。
完全沒寫過程式也看得懂、改得動 —— 這是你（在 Claude 協助下）親手做的第一個 App。

> 設計給**手機**用：可以「加到主畫面」變成像真的 App 一樣的圖示。

---

## 它能做什麼

- 🎯 **設定暑假目標**：分「想學的 / 想認真做的 / 想玩的」三類。
- 📝 **每天打卡**：勾選今天完成了哪些、選心情、留一句話。
- 🎮 **遊戲化**：完成項目得經驗值（XP）、升等、連續打卡天數 🔥、解鎖成就徽章。
- 🤖 **AI 夥伴「阿橘」**：依你今天的表現與心情，給你不同的鼓勵。
- 🔒 **資料只存在你手機上**：用瀏覽器的 localStorage，免帳號、免網路、不上傳。

---

## 怎麼打開來玩

**方法 A：直接開檔案（最快）**
把整個資料夾下載下來，用瀏覽器打開 `index.html` 就能用。

**方法 B：上線變成手機 App（推薦）**
這個專案可以用 **GitHub Pages** 免費上線：

1. 到 GitHub 這個 repo 的 **Settings → Pages**。
2. 「Build and deployment」的 Source 選 **Deploy from a branch**。
3. Branch 選 `claude/github-mobile-connection-j8v34v`、資料夾選 `/ (root)`，按 Save。
4. 等一兩分鐘，GitHub 會給你一個網址（像 `https://<你的帳號>.github.io/-/`）。
5. 用**手機瀏覽器**打開那個網址 → 按「分享 / 選單」→「加入主畫面」。
   之後桌面就會出現「暑假大冒險」的圖示，點開就像 App 一樣！

## 檔案各自負責什麼（給好奇的你）

| 檔案 | 作用 |
|------|------|
| `index.html` | 畫面的骨架（有哪些區塊、按鈕） |
| `styles.css` | 外觀、顏色、動畫。想換色改最上面的 `:root` |
| `app.js` | 核心引擎：目標、打卡、經驗值/等級/連續天數、徽章、存檔 |
| `coach.js` | AI 夥伴「阿橘」的台詞與選句邏輯 |
| `manifest.json` + `icon.png` | 讓它能加到手機主畫面變 App |

---

## 想自己動手改改看？（超簡單的起手式）

- **換夥伴的名字或長相**：開 `index.html`，找到 `🦊` 和「阿橘」改成你喜歡的。
- **加新的鼓勵台詞**：開 `coach.js`，在 `COACH_LINES` 裡的清單加一句你想聽的話。
- **調整經驗值難度**：開 `app.js`，改 `XP_PER_TASK`（每完成一項得幾分）。
- **換主題色**：開 `styles.css`，改 `:root` 裡的 `--brand` 顏色。

改完存檔，重新整理網頁就會看到效果 —— 這就是寫程式最好玩的地方 😎
